# Datos

La distribución original del conjunto BreastDCEDL se guarda en `breastdcedl/`:

```text
breastdcedl/
  dataset/train/
  dataset/test/
  metadata/
  documentation/
  LICENSE
```

Se mantiene esta estructura para respetar las rutas de `metadata/samples.csv`.
Los datos están disponibles en esta copia local, pero no se incluyen en Git.
Su licencia original acompaña a la distribución. No se modifica el contenido
de las imágenes ni de las tablas. El entrenamiento utiliza únicamente train.
